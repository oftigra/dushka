# Душные идеи

Simpson-style QA CV и мемный сайт-портфолио: ручное тестирование, автотесты, мобилки, day/night тема, Matrix-переход, screen locker, баг-жук, devtools-пасхалки и мемная 404.

## Запуск

```bash
npm install
npm run dev
```

Открыть: `http://localhost:3000`.

## Проверки

```bash
npm run lint
npm run build
```

## Деплой

Проект готов для Vercel:

1. Импортировать репозиторий в Vercel.
2. Framework preset: `Next.js`.
3. Build command: `npm run build`.
4. Output directory оставить пустым, Vercel определит Next.js автоматически.
